\# Beat2Genre



Beat2Genre is a machine learning project that classifies music genres using extracted audio features from the GTZAN dataset.



\## Project Overview



The project compares Logistic Regression, Support Vector Machine, and Random Forest classification models using consistent evaluation metrics. The best model is selected using macro-averaged F1-score and saved for future use.



\## Project Status



Project setup completed. Data exploration, preprocessing, model training, benchmarking, evaluation, and model serialization will be completed as the project progresses.
